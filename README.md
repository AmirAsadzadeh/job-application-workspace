# Job Application Workspace

A private, local-first workspace for tracking job applications, position details, submitted resumes, preparation reading, and interview questions.

## Run Locally

```bash
npm install
npm run dev
```

The server creates private runtime data files from the tracked templates in `data/` on first launch. Position records, resumes, uploaded logos, backups, and local caches are excluded from Git.

## Verify

```bash
npm test
npm run build
```
